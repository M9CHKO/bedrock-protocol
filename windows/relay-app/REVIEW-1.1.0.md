# Windows 1.1.0 — Авто 2

2026-09-07. Windows 10/11 x64, Bedrock 1.21.2 и 1.21.100.

## Изменения

- Перенесён общий с Android цикл `AutoCraftStore`: выбранный NBT фиксируется
  при старте; крафт, закрытие верстака, разгрузка в ближайшие сундуки,
  повторение до исчерпания материалов или места.
- В разделе «Модули» появились включение, старт/стоп, статус, счётчики,
  настройки крафта 100–5000 мс и переходов 300–3000 мс, сброс пауз.
  Скорость разгрузки остаётся отдельной настройкой 30–3000 мс.
- Отдельная плавающая кнопка Авто 2 не зависит от активного процесса,
  остаётся при сворачивании реле и в окнах контейнеров. Переносится за
  верхнюю полосу. Обычный TopMost не гарантирует эксклюзивный fullscreen.
- Настройки сохраняются локально. Модуль по умолчанию доступен, но никогда
  не начинает цикл без нажатия. Двойное нажатие во время обработки команды
  не создаёт второй запрос. После отключения модуля новый старт запрещён.
- Общая логика Android 1.3.15: закрытие GUI самим Minecraft, временный
  клиентский воздух и отдельное восстановление по ответу клиента либо
  через 500 мс; серверный мир не меняется. Новое окно ждёт обоих настоящих
  подтверждений закрытия. Смена сеанса отменяет старое восстановление.
- Windows worker выполняет одну фоновую проверку восстановления каждые
  100 мс, без очереди UI-таймеров. Нативные вызовы сериализованы. Завершение
  процесса остаётся ограниченным по времени; Minecraft не завершается.
- Память полных сундуков действует весь запуск, учитывает подтверждённые
  половины двойного сундука. Заголовки слотов читаются без разворачивания
  вложенного NBT. Подробности общей логики — в Android REVIEW-1.3.11–1.3.15.

## Проверки

- Native Release (-O2): сборка успешна; предупреждения устаревшего
  `std::filesystem::u8path`, без ошибок.
- `relay-auto-craft-smoke`: 289 проверок успешно на текущем общем ядре.
- .NET Release: 0 предупреждений, 0 ошибок.
- Упаковка проверяет, что результат — ровно один EXE. Внутри нативное ядро,
  зависимости, .NET, реестры блоков обеих версий, инструкция и лицензии.
  Пользовательские профили, токены и журналы не входят в набор упаковки.
- Сам готовый EXE прошёл 68 проверок (`--self-test`): интерфейс/плавающая
  панель, сериализация настроек, границы пауз в UI и native API, отсутствие
  автозапуска, отказ без NBT, остановка зависшего дочернего процесса,
  закрытие всех окон, перезапуск, освобождение UDP, локальный RakNet ping
  на обеих версиях. Импорт профилей использует искусственные данные.
- 200 переключений страниц, по 500 snapshot/event циклов на каждой версии.
- Визуально проверены экран модулей и плавающая панель Авто 2.
- `git diff --check`: успешно.

Windows Minecraft/реальный сервер в этом прогоне не запускались. Проверки
не доказывают полный цикл в игре. Пользователь подтвердил работающий
Android 1.3.15 до запроса переноса; это отдельное внешнее подтверждение.
