# Проверка Android 1.3.13 / настройки крафта и закрытие окон

Дата: 2026-09-07. versionCode 62, arm64-v8a, minSdk 26, targetSdk 36.

## Исправления

- Авто 2 запрашивает закрытие у Minecraft пакетом container_close с
  server=true и настоящим номером окна, включая знаковый -1 для верстака.
  Раньше запрос отправлялся серверу, как будто клиент уже закрыл интерфейс.
- Следующее окно открывается только после ответа Minecraft и подтверждения
  сервера, затем выдерживается заданная пауза. Нет перехода по одному ответу
  сервера или просто по истечении задержки. При отсутствии подтверждения
  за 8 секунд цикл останавливается с объяснением.
- Повторные и запоздалые закрытия не завершают новый этап. Номер 0 при
  отсутствии собственного окна не считается ручным закрытием. Повторное
  нажатие «Стоп» не сбрасывает ожидание уже отправленного закрытия.
- Настройки доступны в приложении в «Модули» и в CPE → «Автоматизация»:
  пауза между крафтами 100–5000 мс (по умолчанию 1000 мс), между окнами
  300–3000 мс (по умолчанию 700 мс). Значения сохраняются, есть сброс.
  Скорость разгрузки настраивается отдельно. Паузы не отменяют подтверждений.
- При нехватке материалов показывается «Материалы закончились — пополните
  ресурсы». После завершающей выгрузки сообщение сохраняется, а не заменяется
  промежуточным статусом закрытия. Для нового запуска нужно нажать «Старт».
- Добавлены записи auto2_close_request и auto2_close без содержимого NBT
  и данных авторизации. Тяжёлый разбор содержимого сундука не добавлен.

Поведение ответа Nukkit на закрытие сверено с первичным исходным кодом
[Player.java](https://raw.githubusercontent.com/CloudburstMC/Nukkit/master/src/main/java/cn/nukkit/Player.java).
Исправление воспроизведено локальными протокольными тестами; это не проверка
реального интерфейса Minecraft на телефоне.

## Проверка на телефоне

Подключённого Android-устройства нет. Запуск в Minecraft и принятие крафта
живым сервером не проверены. После установки проверить переход верстак →
сундук → верстак, повторное нажатие «Стоп», выбранные паузы и завершение
после исчерпания материалов. При ошибке нужны записи auto2_close_request
и auto2_close из журнала.

Ограничения сохранены: legacy-крафт, без ходьбы, Android-реестр мира только
1.21.100. Авто 2 разгружает все шалкеры, включая уже находившиеся в инвентаре.
