# Проверка Android 1.3.12 / открытие верстака Авто 2

Дата: 2026-09-07. versionCode 61, arm64-v8a, minSdk 26, targetSdk 36.

## Исправления

- Разрешён номер окна верстака 255 (знаковый -1), используемый Nukkit.
  Проверяются также тип и координаты; для сундуков диапазон не расширен.
  Исходное поведение сервера: [BlockCraftingTable.java](https://github.com/CloudburstMC/Nukkit/blob/master/src/main/java/cn/nukkit/block/BlockCraftingTable.java).
- После отклонения уже полученного чужого окна запрос завершается сразу:
  повторный ложный тайм-аут не появляется. Чужое окно не закрывается.
  Повторный ответ своего окна не сбрасывает стадию и задержку крафта.
  Закрытие передаёт знаковый номер -1 обратно в протокол.
- После ручного клика и совпавшего ответа сервера запоминаются координаты,
  runtime ID и сторона блока. Предел 32 записи, срок 2 минуты, сброс при
  смене мира/сеанса. Неподтверждённые клики не запоминаются. Записи помогают
  при неполных чанках, но не отменяют дистанцию и известные препятствия.
- Отбор SubChunk теперь учитывает смещения отдельных секций: дальнее
  начало пакета больше не приводит к потере его ближних секций. Дальние
  секции не декодируются в блоки для режима только Авто 2.
- В журнал добавлен auto2_open: номер, тип, координаты, принятие ответа.
  NBT и данные авторизации в эти записи не включаются.

Ошибка номера окна воспроизведена на уровне протокола. Точная причина
отсутствия блока на третьем фото без журнала не установлена; добавлены
исправление фильтра секций и ограниченный резервный поиск по ручным открытиям.

## Проверка на телефоне

Подключённого Android-устройства нет. Запуск в Minecraft и принятие крафта
живым сервером не проверены. Установить обновление, выбрать NBT, открыть и
закрыть вручную верстак и нужные сундуки, затем запустить Авто 2 рядом с ними.
Проверить первый результат, разгрузку и остановку. Ограничения версии 1.3.11
сохранены: legacy-крафт, без ходьбы, Android-реестр мира только 1.21.100.
