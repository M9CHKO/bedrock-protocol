# CPE Relay Android 1.5.2-Modules

Android 8+ · arm64-v8a · versionCode 76 · optimized native Release,
signed with the existing test/debug certificate.

## Изменения

- Новый тёмный интерфейс с мягким фиолетовым акцентом: подключение, модули,
  журнал и настройки. Каждая функция открывается отдельно.
- Переработано именно меню **поверх Minecraft**: компактные плитки в две
  колонки, закреплённый заголовок и возврат, ограниченная высота в альбомной
  ориентации. 16 отдельных модулей вместо длинной страницы автоматизаций.
- Плавающие кнопки по умолчанию скрыты. Включение: **Настройки → Плавающие
  кнопки → Меню CPE**; кнопки разгрузки, автокрафта, ZIP и заполнения выбираются отдельно.
  Скрытие интерфейса не выключает функции.
- Постоянная загрузка до 4000 карт, без кнопки запуска: до 8 обновлений и
  **512 КиБ/с**, по одной карте за раз. Последнее ускорение до 640 КиБ/с отменено.
- Общая C++ библиотека перехватывает карты до обычной пересылки, объединяет
  обновления в ограниченном дисковом хранилище и отправляет через планировщик.
  Лимиты: 8 МиБ буферов, 512 МиБ диска. Отдельно ограничены запросы карт
  к серверу. Прямого обхода при ошибках и переполнении нет.
- No Render управляет только сущностями, независимо от карт. Выключение
  восстанавливает сохранённых акторов с актуальным tick метаданных.
  Данные блоков сундуков и шалкер-боксов не фильтруются.
- ZIP-крафт, платформа, разгрузка, автокрафт, тотем и броня имеют свои страницы.
  Паузы ZIP-крафта сворачиваются, команды выполняются вне потока интерфейса.
  Числовой ввод получает фокус только после нажатия; «Готово», возврат и
  сворачивание меню возвращают обычный режим без захвата клавиатуры.
- Обновлены основной README, инструкция Android и документация общих модулей.

## Проверка и ограничения

Пройдены **106 Android-тестов**, сборка `assembleRelease` и `lintRelease`
(без ошибок, остаются предупреждения). Проверены отдельные настройки,
миграция видимости, переходы по всем 16 модулям, повторное включение/выключение
No Render и портретное/альбомное меню. UI дополнительно просмотрен по
изображениям, отрисованным Android через Robolectric native graphics.

Общий C++ код с текущим лимитом 512 КиБ/с ранее прошёл 9 выбранных CTest,
включая локальную пересылку, очередь запросов, ёмкость 4000 карт, запрет
прямой пересылки и восстановление сущностей. В этом APK собран тот же исходный
код; нативные CTest выполнялись на ПК, не на Android-устройстве.

Это не гарантия работы конкретного публичного сервера или отрисовки всех
карт на каждом телефоне. Итоговый APK требует проверки в Minecraft на устройстве.
Счётчики отправки не означают отрисовку; очень большие метаданные могут исчерпать
дисковый лимит до 4000 ID. Подробности: [очередь карт](https://github.com/M9CHKO/bedrock-protocol/blob/android-v1.5.2-modules/docs/map-delivery.md).

APK обновляет предыдущие тестовые версии с тем же сертификатом. Если Android
сообщает о несовместимой подписи, не удаляйте старое приложение без сохранения
нужных файлов и настроек.
